# 🚗⚡ Electric Vehicle (EV) Data Analysis  

## 📌 Overview  
This project analyzes **Electric Vehicle (EV) adoption trends** using **Python, Pandas, Matplotlib, and Seaborn**. It explores factors such as:  
✅ Vehicle Make & Model  
✅ Electric Range Distribution  
✅ EV Registration Trends  

## 📊 Dataset  
📂 **File:** `Electric_Vehicle_Population_Data.csv`  
📌 Contains details on:  
🔹 EV Registrations 🚙  
🔹 Manufacturer & Model 🏭  
🔹 Electric Range (Miles) 🔋  

## 🔍 Features of Analysis  
📈 **EV Adoption Over Time**  
🏙️ **EV Distribution by County & City**  
🔋 **Electric Vehicle Type Distribution**  
🏭 **Top Manufacturers & Models**  
🔄 **Electric Range Distribution**  
📊 **Market Forecasting for EV Growth**
